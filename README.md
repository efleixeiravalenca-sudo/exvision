# EX.VISION — Identidade Visual
Projeto de identidade visual desenvolvido por Everton Luiz para a marca EX.VISION.

## Entregas
- Logo
- Banner principal
- Guia rápido de identidade visual
- Página de apresentação do projeto

## Conceito
Visual minimalista, tecnológico e de alto contraste, usando preto, branco, cinza e azul como cores principais.

## Como apresentar no portfólio
Use `banner-exvision.svg` como imagem principal do projeto e `case-study.html` como página detalhada.
